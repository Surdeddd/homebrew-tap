# Surdeddd/tap

Homebrew formulae for [agent-widgets](https://github.com/Surdeddd/agent-widgets) — native macOS desktop widgets built by AI agents.

```sh
brew install surdeddd/tap/agent-widgets
aw doctor
```

The formula builds `aw` from source with your Xcode (16.3 or newer) and installs XcodeGen. Upgrade with `brew upgrade agent-widgets`.
